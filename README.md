
# Cyber Cafe Management System

A console-based management application built in C language for tracking cyber cafe usage, customer allocations, and billing.

## 📌 Features
- **User Session Management:** Allocate and monitor computer sessions.
- **Time & Billing Calculation:** Automatically computes total session duration and usage charges.
- **Data Persistence:** Uses C file handling (`stdio.h`) and structured data types (`struct`) to save customer logs.

## 🛠️ Built With
- **Language:** C
- **IDE / Environment:** Code::Blocks / Visual Studio Code

## 🚀 How to Run
1. Clone or download this repository.
2. Open `CyberCafeManagement.cbp` in Code::Blocks (or compile `cyber_cafe.c` using GCC/Clang).
3. Build and run the project (`Ctrl + F9` or `F9` in Code::Blocks).
